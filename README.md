# Smoothing-priors-for-blind-deblurring-codes

## MATLAB Codes
1. Download Smoothing priors blind deblur codes.rar.
2. Put test images into folder 'dataset'.
3. Run Mytest_smoothing.m

Datasets can be found via [pan](https://jspan.github.io/projects/text-deblurring/index.html), [Köhler](https://jspan.github.io/projects/text-deblurring/index.html).
